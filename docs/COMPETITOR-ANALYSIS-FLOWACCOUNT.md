## 4. คุณสมบัติเด่น (Key Features) — เปรียบเทียบระดับแพ็กเกจ

### Core Accounting (ทุกแพ็กเกจ)
- สร้างเอกสารขาย (ใบเสนอราคา → ใบวางบิล → ใบส่งสินค้า/ใบกำกับภาษี → ใบเสร็จรับเงิน)
- เอกสารซื้อ/ค่าใช้จ่าย (ใบสั่งซื้อ → ใบรับสินค้า → ใบบันทึกค่าใช้จ่าย → ใบเตรียมจ่าย)
- รายงานสรุปยอดขาย/ภาษี, แดชบอร์ดการเงิน
- กระทบยอดธนาคาร (Bank Reconcile) — นำเข้ารายการเดินบัญชีทุกธนาคาร
- ส่ง e-Tax Invoice by Time Stamp
- รองรับสกุลเงินต่างประเทศ
- จัดการสินทรัพย์ + ค่าเสื่อมราคา
- ดูงบการเงินแบบเรียลไทม์

### Standard ขึ้นไป
- กระทบยอดธนาคารอัตโนมัติ (Auto Bank Feed — ฟรีปีแรกกับ KBank, TTB)
- นำเข้ายอดขายจาก Food Delivery / POS อื่น
- ยื่นหัก ณ ที่จ่ายออนไลน์ + จัดการภาษีมูลค่าเพิ่ม

### Pro ขึ้นไป
- ไม่จำกัดจำนวนผู้ใช้
- บริหารสต็อกสินค้า (หลายหน่วยนับ, สูงสุด 50 คลัง)
- เปิดเอกสารจัดซื้อ + รับสินค้าเข้าสต็อก
- ระบบแบ่งรับชำระ / รับมัดจำ / แบ่งส่งสินค้า
- ดูความเคลื่อนไหว ราคาซื้อ/ขายเฉลี่ย

### Pro Business ขึ้นไป
- จัดการหลายคลังสินค้า
- เชื่อมต่อ Open API
- เชื่อมต่อ E-commerce (Shopee, Lazada, TikTok Shop, Wongnai POS)
- ซิงค์ข้อมูลบิล + สต็อกหลายร้านค้าในที่เดียว

## 11. ข้อเสนอแนะเชิงกลยุทธ์ (Recommendations for MBS / ผู้ใช้)

### หากต้องการแข่งขันโดยตรง
1. **เน้นความแตกต่าง:** FlowAccount มี Partner Network 6,000+ — ถ้า MBS ไม่มี ควรสร้าง Value Proposition ที่แตกต่าง (เช่น: ราคาถูกกว่า, ฟีเจอร์ที่ FlowAccount ไม่มี, หรือกลุ่มลูกค้าเฉพาะทาง)
2. **Freemium Strategy:** FlowAccount ให้ Free ตลอดชีพ — ถ้า MBS ไม่มี Free Tier อาจเสียเปรียบในการดึงผู้ใช้ใหม่
3. **AI Integration:** AI Connector (MCP) เป็นจุดขายใหม่ — ควรตรวจสอบว่า MBS มีแผนหรือไม่
4. **Bank Integration:** ถ้า MBS ต้องการแข่งในตลาดไทย ต้องรองรับธนาคารไทยอย่างน้อย KBank, SCB, TTB
5. **Add-on Model:** พิจารณาแยก Payroll / Leave Management / Multi-store เป็น Add-on เพื่อเพิ่มรายได้ต่อผู้ใช้

### หากใช้เป็นข้อมูลอ้างอิง (Benchmark)
- **ราคา:** Standard (฿165/ด. รายปี) / Pro (฿249/ด. รายปี) — ใช้เป็น Benchmark สำหรับการตั้งราคา MBS
- **Feature Set:** กระทบยอดธนาคาร, สต็อก, ภาษี, เงินเดือน, POS, AI — ใช้เป็น Checklist ว่า MBS ต้องมีอะไรบ้าง
- **Marketing:** Search Ads (Exact Match) + Free Trial + Demo Booking — ใช้เป็น Template สำหรับแคมเปญของ MBS

## 12. สรุปสั้น (Executive Summary)

**FlowAccount** เป็นคู่แข่งที่แข็งแกร่งในตลาด **โปรแกรมบัญชีออนไลน์สำหรับ SME ไทย** มีระบบนิเวศครบวงจร (บัญชี + POS + เงินเดือน + สต็อก + E-commerce + AI), มี Social Proof ที่แข็งแกร่ง, และใช้กลยุทธ์ **Freemium + Add-on + B2B2C (ผ่านนักบัญชี)** ที่มีประสิทธิภาพสูง

**จุดแข็งที่น่ากลัวที่สุด:**
- ฟรีตลอดชีพ (ดึงผู้ใช้เข้า Funnel ง่าย)
- Bank Integration ลึก + AI Connector (ตอบโจทย์เทรนด์)
- Partner Network 6,000+ นักบัญชี (ช่วยขายโดยไม่ต้องจ่ายค่าโฆษณาเพิ่ม)

**ช่องว่างที่ MBS อาจใช้ประโยชน์:**
- ความซับซ้อนของแพ็กเกจ (Free → Standard → Pro → Pro Business + Add-ons หลายตัว) — อาจทำให้ลูกค้าสับสน
- Payroll เป็น Add-on แยก — อาจทำให้รู้สึกว่า "ไม่ครบ" เมื่อเทียบกับคู่แข่งที่รวมในแพ็กเกจ
- ไม่มีการเปรียบเทียบโดยตรงกับคู่แข่ง — ปล่อยให้ลูกค้าต้องค้นหาเอง
